# Namespace for Canton Network

The prefix `canton` designates the CAIP-conformant schemata of the Canton namespace.

## Governance

Protocol and application standards for Canton Network are specified as Canton Improvement Proposals (CIPs).
[CIP-0000][] defines the process: authors draft a CIP, discuss it on the `cip-discuss` mailing list, and submit a pull request to the [CIP repository][].
A Super Validator sponsor and a second Super Validator endorser are required before the CIP is sent to `cip-vote`.
Super Validator rights holders then approve it by a two-thirds majority in a 10-day GitHub Team Vote.

This namespace documents CAIP identifier mappings for external, chain-agnostic consumption.
If a later CIP contradicts or extends the contents of these specifications, that CIP is authoritative over this CASA profile.
