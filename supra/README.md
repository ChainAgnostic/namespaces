# Namespace for Supra chains

## Introduction

Blockchains in the "supra" namespace are identified by their numeric `chain_id`;
each network is maintained by a set of validators with its own REST RPC
endpoints. Supra is a Layer 1 blockchain built on Move, with vertically
integrated services — native price oracles, distributed verifiable randomness
(dVRF), and on-chain automation.

## Syntax

The namespace "supra" refers to the Supra open-source blockchain platform.
